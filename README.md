# AlkorTech

AlkorTech mobil uygulamalarının herkese açık sayfaları. GitHub Pages ile
https://alkortech.github.io/ adresinde yayımlanır.

Her uygulama kendi klasöründedir:

```
<uygulama-adi>/gizlilik-politikasi/index.html
```

Yeni uygulama eklerken klasörünü oluştur ve `index.html` listesine ekle.
Bu repoya kod, anahtar veya kişisel veri konmaz: içindeki her şey herkese açıktır.
